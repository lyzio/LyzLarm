## Anatole 0.3.0 – smart wake

LyzLarm is now called **Anatole – Sleep tracker & alarm**, after the Greek goddess of sunrise.

- **Smart wake window:** give an alarm a window (15–45 min, 30 by default). While you sleep with tracking on, it rings at the first clear light sleep in the window, right away if you are already awake, and always by your latest time.
- **Why it rang:** the ringing screen and the Morning screen show the reason (light sleep, already awake, end of window, fixed time).
- **Smart snooze:** while tracking, snooze rings at the next light sleep after half the snooze, at the latest when it ends.
- **Sensitivity:** Cautious / Balanced / Eager in Settings › Alarm defaults; the first 7 nights use Cautious while Anatole learns.
- **Mornings:** time asleep, time in bed, time to fall asleep, an estimated sleep-stage curve, and the wake window in the graph. Past nights show time asleep and in bed.
- **Out of bed:** run the 10-minute empty bed test once (Settings › System check); time out of bed is then counted as awake and shown in the graph, when the phone can tell an empty bed from you lying still.
- **Snooze lock (optional):** solve a math, memory or typing challenge, or scan a barcode, before you can snooze or turn the alarm off; plus an optional stay-awake check.
- **Fixes:** stopping tracking before the alarm now turns off that morning's alarm (#71); the bedtime reminder's Start sleep now starts tracking (#26).
- Also in this release (from v0.2 testing): one fixed test signing key, so test builds install over each other; website rebuilds only on merges and releases; Morning screen layout fixes and a battery-used line; export shows progress.

Existing alarms keep a fixed time after updating; turn on the wake window in Edit alarm.

Install: download `Anatole-0.3.0.apk` below on your phone and open it (installs over 0.2 and keeps your nights). Android 8.0 or newer.
