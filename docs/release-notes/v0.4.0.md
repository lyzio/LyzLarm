## Anatole 0.4.0 – ready for Google Play

- **New package name** `se.lyzio.anatole` (Google Play fixes it at the first upload). This version installs as a **new app** next to the old one.
- **Import night (CSV)** in Settings › Data: brings back nights exported from v0.2 or v0.3, so your history survives the switch. Pick several files at once; a night already saved is skipped.
- **Tracking follows your next alarm:** turning an alarm off or on, adding, deleting or editing one after Start sleep now applies at once to smart wake, the Bedtime screen and Hold to stop (until an alarm has rung).
- **Bedtime screen layout:** labels no longer break mid-word, long values wrap, the screen scrolls and "Hold to stop tracking" keeps its full size on small screens.
- **Google Play:** every release now also builds a signed Play bundle and uploads it to internal testing, with the store text, icon, feature graphic and screenshots kept in the repository (screenshots are rendered from the real screens). [Privacy policy](https://lyzio.github.io/Anatole/privacy.html) added, linked from About.
- Sound tracking moves to v0.5.

**Coming from 0.3 or earlier:** in the old app, export each night (Past nights › night › Export › Save to file). Install `Anatole-0.4.0.apk` below, import the files in Settings › Data › Import night (CSV), check they are there, then uninstall the old Anatole. Set your alarms again and run the test alarm. Android 8.0 or newer.
